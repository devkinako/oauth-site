プライバシーポリシー

最終更新: 2026-09-05

health-ingest（以下「本アプリ」）は、開発者本人が自分の健康データを管理するために作った個人用ツールです。 利用者は開発者本人だけで、第三者には提供していません。

取得するデータ

Google Health API を通じて、利用者本人が同意した範囲の睡眠・心拍・活動・健康指標のデータを取得します。 位置情報のスコープは要求しません。

データの利用目的

取得したデータは、本人のベースラインからの偏差を計算して体調を表示するためだけに使います。

保存場所と共有

データは利用者本人が管理する自宅 LAN 内のサーバーにのみ保存します。 クラウドサービスや第三者に送信・共有・販売することはありません。広告にも利用しません。

削除

利用者は Google アカウントの「サードパーティのアプリとサービス」から本アプリのアクセス権をいつでも取り消せます。 保存済みのデータは、サーバー上のデータベースを削除することで消去できます。

Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の利用は、限定的な使用の要件を含む Google API Services User Data Policy に従います。

連絡先

OAuth 同意画面に記載のサポートメールアドレスまでご連絡ください。

Privacy Policy (English)

Last updated: 2026-09-05

health-ingest ("the app") is a personal tool built by its developer to manage the developer's own health data. The developer is the only user. The app is not offered to third parties.

Data collected

Through the Google Health API, the app reads sleep, heart rate, activity and health metric data within the scopes the user has consented to. The app does not request the location scope.

How data is used

The data is used only to compute deviations from the user's own baseline and to display the user's condition.

Storage and sharing

Data is stored only on a server on the user's home network, operated by the user. It is never sent to cloud services, shared with, or sold to third parties, and it is not used for advertising.

Deletion

The user can revoke the app's access at any time from the "Third-party apps & services" page of their Google Account. Stored data can be erased by deleting the database on the server.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Use the support email address shown on the OAuth consent screen.
