プライバシーポリシー

最終更新: 2026-09-05

health-ingest（以下「本アプリ」）は、利用者が自身の健康データを把握するための非商用ツールです。 本ポリシーは、本アプリが取得するデータとその取り扱いについて説明します。

取得するデータ

Google Health API を通じて、利用者本人が同意した範囲の睡眠・心拍・活動・健康指標のデータを取得します。 位置情報のスコープは要求しません。

データの利用目的

取得したデータは、利用者本人のベースラインからの偏差を計算して体調を表示するためだけに使います。

保存場所と共有

データは、運営者が管理する自宅ネットワーク内のサーバーにのみ保存します。外部のクラウドサービスは利用しません。 第三者に送信・共有・販売することはありません。広告にも利用せず、機械学習モデルの学習にも使用しません。

削除

利用者は Google アカウントの「サードパーティのアプリとサービス」から本アプリのアクセス権をいつでも取り消せます。 保存済みデータの削除をご希望の場合は、下記の連絡先までご連絡ください。

Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の利用は、限定的な使用の要件を含む Google API Services User Data Policy に従います。

連絡先

OAuth 同意画面に記載のサポートメールアドレスまでご連絡ください。

Privacy Policy (English)

Last updated: 2026-09-05

health-ingest ("the app") is a non-commercial tool that helps users understand their own health data. This policy explains what data the app collects and how it is handled.

Data collected

Through the Google Health API, the app reads sleep, heart rate, activity and health metric data within the scopes the user has consented to. The app does not request the location scope.

How data is used

The data is used only to compute deviations from the user's own baseline and to display the user's condition.

Storage and sharing

Data is stored only on a server on the operator's home network. No external cloud services are used. It is never sent to, shared with, or sold to third parties. It is not used for advertising, nor to train machine learning models.

Deletion

The user can revoke the app's access at any time from the "Third-party apps & services" page of their Google Account. To request deletion of stored data, please use the contact address below.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Use the support email address shown on the OAuth consent screen.
